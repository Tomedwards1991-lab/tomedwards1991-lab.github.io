# edwards.phd

The personal website of Thomas Edwards. GitHub Pages publishes the static files in the root of the `main` branch.

Edit the English page in `en/index.html`, the translations in `cy/`, `mi/` and `bg/`, and shared styles in `style.css`. The homepage and the old Welsh URL forward to `/en/` and `/cy/`. To preview locally, run `python3 -m http.server` from this directory and visit `http://localhost:8000`.
